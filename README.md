# StudyBuddy (Mobile)

A cross-platform mobile productivity app built with React Native for students to manage tasks, improve focus, and organize study routines.

---

## Features

- Pomodoro timer for productivity sessions
- Task management system
- Eisenhower Matrix prioritization
- Mobile-optimized UI/UX
- Offline task tracking
- Simple and fast performance

---

## Tech Stack

- React Native
- JavaScript
- React Navigation
- Async Storage (if used)

---

## Key Highlights

- Cross-platform mobile support
- Lightweight productivity tool
- Seamless UX for students
- Consistent with web version design
